# Les Cendres d’Astréa — V4

Version livre-jeu propre : transitions plus cohérentes, rencontres bloquantes, lancer de dés, sauvegarde, quêtes, secrets et illustrations noir et blanc.

## Installation

```bash
npm install
npm run dev
```

## Déploiement Vercel

- Framework : Vite
- Build command : `npm run build`
- Output directory : `dist`

Ne pas ajouter `package-lock.json`, `postcss.config.js` ou `tailwind.config.js`.
